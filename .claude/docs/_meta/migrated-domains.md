# Мигрированные домены

Домены, переведённые на openspec-требования (`spec.md` + `references/`). Список
ведётся руками: `spec_check.py` проверяет по нему только перечисленные домены и
молчит про остальные, которые ещё живут в старом формате `<domain>-rules.md`.

Домен попадает сюда в том же коммите, в котором появляется его `spec.md`.
