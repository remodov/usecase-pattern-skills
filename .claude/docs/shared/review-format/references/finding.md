# Разметка отчёта ревью

Требования к содержанию — `../spec.md`.
Здесь только форма.

## Находка на одной строке

```
<путь>:<номер>  [<домен>/<требование>]  <критично | предупреждение | замечание>
  Строка: <дословное содержимое строки, как показало чтение файла>
  Проблема: <одна фраза>
  Почему: <краткая цитата требования>
  Как исправить: <конкретное предложение, лучше сниппетом>
```

## Находка на диапазоне

```
<путь>:<начало>-<конец>  [<домен>/<требование>]  <уровень>
  Строка:
    Начало (<номер>): <первая строка диапазона дословно>
    Конец  (<номер>): <последняя строка диапазона дословно>
  Проблема: <одна фраза>
  Почему: <краткая цитата требования>
  Как исправить: <конкретное предложение>
```

## Резюме отчёта

```
Резюме:
  Критично:        <n>
  Предупреждение:  <n>
  Замечание:       <n>
  Вердикт: <соответствует | незначительные отклонения | требует доработки>
```

Вердикт считается по числам, а не по впечатлению: нет критично и предупреждений
— соответствует; есть предупреждения — незначительные отклонения; есть хотя бы
одно критично — требует доработки.
