# Ревью работы с контрактом

## Откуда берутся правила

**`openspec/specs/api/spec.md`** проекта — источник правды. В каждой
находке цитируй requirement ID. Сводная таблица инвариантов — `AGENTS.md`
(собирается `bun run spec:sync`, руками не правится).

**Читай поле «Гейт» каждого требования.** Оно говорит, ловит нарушение машина
или человек. Требование с гейтом «нет» не поймает никто, кроме тебя — смотри
такие внимательнее прочих. Поле «Не ловит» прямо называет, что проскакивает
мимо гейта: это готовый список того, что нужно проверить глазами.

**Проверь, что гейты включены.** Требование обещает механизм — убедись, что он
есть в проекте: `bun run generate:api`, `typecheck`, `map:check` и правило `fsd/no-public-api-sidestep` в steiger. Обещанный, но не включённый гейт — **отдельная
находка**, и она важнее единичного нарушения.

Если `openspec/specs` в проекте нет — скажи прямо: требований не объявлено,
ревьюить не против чего. Предложи завести по образцу `next-ssr`, и дальше
выдавай находки как мнение, а не как нарушения.

## Что смотреть

- **Сеть только через сгенерированные хуки** (`api/network-via-generated-hooks`): ручной `fetch` или `axios` в компоненте — находка.
- **Контракт приезжает npm-пакетом** (`api/contract-as-npm-package`): локальный `openapi.yaml` означает копию, которая молча разойдётся с сервисом.
- **Сгенерированный код руками не правится** (`api/generated-code-immutable`) — правка переживёт ровно до следующего `generate:api`. Гейта нет.
- **Ключи инвалидации — из сгенерированного кода** (`api/invalidation-keys-from-generated`): написанный руками ключ компилируется и молча перестаёт обновлять список. Гейта нет — это самая дорогая находка области.
- **Пагинация серверная** (`api/server-side-pagination`): `page` и `size` в запрос, `totalPages` из конверта. Нарезать полученный массив нельзя даже на десяти записях.
- **Размер страницы объявлен один раз** (`api/page-size-single-source`).
- **`operationId` у каждой операции** (`api/operationid-required`), секция сервиса в `orval.config.ts` по образцу (`api/orval-section-shape`).
- **Вошедшего отдаёт эндпоинт действующего лица** (`api/me-endpoint-convention`).

## Формат вывода

Находка: `<requirement-id>` — что не так, файл и строка, почему это ломается,
как надо. Сгруппируй: критично (ломает прод или контракт) / важно / замечание.
В конце — список требований с гейтом «нет», которые ты проверил глазами.
