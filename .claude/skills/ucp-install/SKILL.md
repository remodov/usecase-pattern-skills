# Установка UCP-скиллов в проект (Claude как мастер)

Ты ставишь UCP-скиллы в проект пользователя, сам проводя «интервью» вместо bash-`--wizard`: детектишь параметры
из проекта, подтверждаешь, запускаешь `install.sh`. Аргумент — каталог-цель (если не задан — спроси/возьми cwd).

## Шаги

1. **Найди `install.sh` репо скиллов.** Он в корне репо = `${CLAUDE_SKILL_DIR}/../../../install.sh` (этот скилл
   лежит в `<repo>/.claude/skills/ucp-install/`). Проверь существование (`ls`); если путь не сошёлся (симлинк из
   личных `~/.claude/skills/`) — найди `install.sh` поиском вверх от репо или спроси путь у пользователя.

2. **Определи каталог-цель.** Из `$ARGUMENTS`; иначе спроси (дефолт — текущий проект). Это НЕ репо скиллов.

3. **Авто-детект (не спрашивай то, что видно):**
   - **Язык:** `pyproject.toml`/`uv.lock`/`setup.py` → `python`; `build.gradle*`/`pom.xml` → `java`; `go.mod` → `go`;
     `package.json`+`tsconfig.json` (NestJS) → `node`.
   - **Специализация (track):** `playwright.config.*`/`cypress.config.*` → `e2e`; `package.json` с `react`/`vue` +
     `index.html`/`src/components` → `frontend`; иначе → `backend`.
   - Несколько маркеров (моно-репо: и backend, и frontend) — предложи мульти-трек.

4. **Подтверди и добери недостающее через `AskUserQuestion`:** покажи задетекченные track + lang, дай поправить;
   спроси **профиль** (`full` — всё · `rest` — REST/UCP-сервис · `data` — data-heavy). Если детект уверенный —
   один вопрос (профиль); если нет — добавь track/lang.

5. **Покажи команду и запусти** (после подтверждения):
   ```
   UCP_TRACK=<track> UCP_LANG=<lang> UCP_PROFILE=<profile> bash <repo>/install.sh <target>
   ```
   `UCP_TRACK` — список через запятую для мульти-трека. Для `frontend`/`e2e` предупреди, что скиллов пока нет
   (поставит 0) — если только их не добавили.

6. **Проверь результат:** `bash <repo>/install.sh --check <target>` — отчёт о симлинках/блоках. Кратко резюмируй
   пользователю: сколько скиллов, какой срез (track/lang/profile), всё ли на месте.

## Важно

- **Это side-effecting** — install.sh пишет симлинки, мержит `settings.json`, managed-блоки в `CLAUDE.md`/`.gitignore`.
  Запускай только **после явного подтверждения** пользователя (шаг 4 уже его собирает).
- **Холодная установка:** этот скилл сам должен быть доступен ДО установки. Для этого он ставится в личные
  `~/.claude/skills/ucp-install` один раз (симлинком на репо). Если пользователь спрашивает «как сделать, чтобы
  работало в любом проекте» — подскажи: `ln -s <repo>/.claude/skills/ucp-install ~/.claude/skills/ucp-install`.
- **Смена конфигурации** (добавить трек/сменить язык) — повторный запуск с новыми флагами; install.sh идемпотентен
  (чистит свои старые симлинки, ставит выбранный срез).
- Не редактируй install.sh из этого скилла — только запускай. Меняется install.sh отдельно.
