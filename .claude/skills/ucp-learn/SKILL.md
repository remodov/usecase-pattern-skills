# Project Learning — опыт с подтверждением

Накапливай только устойчивые проектные нюансы. Не включай фоновое наблюдение и не делай выводы после любой задачи. Хранилище — `.ucp/learning/` в текущем проекте, не в репозитории скиллов.

## Границы

- Только `scope: project`. Не переносить опыт в канонические `.claude/skills/**`, другой проект или публичный репозиторий.
- Не записывать секреты, токены, персональные данные и содержимое закрытых файлов. Evidence — короткое описание факта, теста, ошибки или исправления, а не сырой транскрипт.
- Первое наблюдение не даёт права менять поведение. Нужны минимум **два разных подтверждения** одной закономерности.
- Канонические скиллы не редактируются. Применённое знание живёт в `.ucp/learning/playbook.md`.

## Порядок

1. **Определи урок.** Подходит повторяющаяся поправка пользователя, одинаковый сбой и его разрешение, подтверждённое проектное соглашение. Разовая опечатка, внешний сбой или просто завершённая задача опытом не считаются.

2. **Запиши наблюдение через runtime.** Определи реальный путь текущего `SKILL.md`; корень исходного репозитория — три уровня выше каталога `ucp-learn`. Выполни:
   ```bash
   python3 <repo>/tools/ucp_learning.py record --root <project> \
     --category <область> --lesson <короткая формулировка нюанса> --evidence <факт подтверждения>
   ```
   Если такое наблюдение уже было, добавь **другое** evidence. Повтор той же фразы без нового факта не увеличивает счётчик.

3. **Проверь статус.**
   - `collecting` — пока одно подтверждение. Ничего не применяй и не задавай вопрос: продолжай обычную работу.
   - `pending` — есть минимум два разных подтверждения. Покажи пользователю формулировку, evidence и предложенный текст playbook.
   - `applied` / `rejected` — новых действий не требуется.

4. **Спроси явно:** «Применить этот нюанс к текущему проекту?» Не применяй молча и не считай согласие прошлой задачи разрешением на новый урок.

5. **Примени только после «да»:**
   ```bash
   python3 <repo>/tools/ucp_learning.py apply --root <project> --id <candidate-id> --yes
   ```
   Если пользователь отказался:
   ```bash
   python3 <repo>/tools/ucp_learning.py reject --root <project> --id <candidate-id>
   ```

6. **Используй знание в следующих задачах.** Перед релевантной работой прочитай `.ucp/learning/playbook.md` и применяй только относящиеся к задаче нюансы. Это проектные правила, а не универсальная истина и не замена `.claude/docs/`.

## Результат

Сообщи: количество подтверждений, статус, задан ли вопрос и был ли нюанс применён. Не заявляй «обучено», если применения не было.
