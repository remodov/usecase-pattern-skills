# Платёжная интеграция — проектирование (Java / Spring Boot)

## Инструкции

1. **Прочитай** `.claude/docs/backend/payment-integration/spec.md` и `references/java/implementation.md`. Связанные: `backend/resilience/spec.md` (обвязка адаптера), `backend/distributed-patterns/spec.md` (идемпотентность и компенсации), `backend/scheduler/spec.md` (дозабор), `backend/auth-patterns/spec.md` (журнал действий, персональные данные).

2. **Спроектируй флоу тремя шагами:** зарегистрировать намерение → списать → зафиксировать исход. Каждый шаг — по естественному ключу операции, с чтением до записи и действием только для незавершённой операции.

3. **Заложи обязательное:**
   - блокировка по заказу на время попытки (`pg_advisory_xact_lock` либо `FOR UPDATE` по строке платежа);
   - единственный `ProviderStatusMapper`, наружу — доменные значения;
   - два типа исключений: транспортное (операция остаётся незавершённой) и бизнес-отказ (конечное состояние);
   - регламентный дозабор незавершённых и закрытие по сроку;
   - `BigDecimal` и `numeric`, явное округление;
   - запись в журнал действий на каждую денежную операцию, чувствительные данные не покидают адаптер.

4. **Самопроверка** и предложи `ucp-payment-integration-review`.

## Чего не генерировать

- Создание операции без предварительного чтения по естественному ключу.
- Перевод тайм-аута в отказ (`payment-integration/transport-error-keeps-operation-retryable`).
- Интерпретацию кодов провайдера в нескольких местах.
- `double` для сумм; номер карты и полные ответы провайдера в журнале.
