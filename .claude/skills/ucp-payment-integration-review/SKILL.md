# Платёжная интеграция — ревью (Java / Spring Boot)

## Инструкции

1. **Прочитай** `.claude/docs/backend/payment-integration/spec.md`; идиома — `references/java/implementation.md`.
2. **Определи объект ревью:** названные файлы либо `git diff` — адаптер провайдера, сервис оплаты, отображение статусов, задание дозабора, DDL таблицы платежей.
3. **Прогон по требованиям** `payment-integration/*`; формат находки — `shared/review-format/spec.md`.

## На что смотреть в первую очередь

- Создание операции без чтения по естественному ключу — критично: повтор даёт второй платёж.
- Отсутствие блокировки по заказу — критично: два нажатия проходят обе проверки.
- Тайм-аут, переведённый в отказ, — критично: деньги списаны, заказ отменён.
- Коды провайдера, интерпретируемые вне единственного отображения.
- `double` в суммах, отсутствие явного округления.
- Отсутствие дозабора незавершённых: операции висят вечно.
- Номер карты, коды подтверждения, полные ответы провайдера в журнале.
