# Фоновая обработка — ревью (Java / Spring Boot)

## Инструкции

1. **Прочитай** `.claude/docs/backend/scheduler/spec.md`; идиома — `references/java/implementation.md`.
2. **Определи объект ревью:** названные файлы либо `git diff` — `@Scheduled`, обработчики заданий, DDL таблиц заданий, `@ConfigurationProperties` расписаний.
3. **Прогон по требованиям** `scheduler/*`. Формат находки — `.claude/docs/shared/review-format/spec.md`, ссылайся на ID требования.
4. **Проверь, что обещанный гейт заведён:** у большинства требований домена гейт — `ревью`; `archunit:ScheduledMethodsAreGuardedTest` обязан существовать в проекте, иначе это отдельная находка уровня «важно».

## На что смотреть в первую очередь

- Тик без `@SchedulerLock` — критично, если тик сам выполняет работу; тик, запускающий атомарный захват идемпотентной работы, без блокировки допустим только явным исключением в `ScheduledMethodsAreGuardedTest` с обоснованием.
- `fixedRate` без `lockAtLeastFor = interval` — предупреждение: серия догоняющих запусков после длинного прогона.
- Свойства процессинга без `@Validated` — предупреждение: неверное значение молча делает тик пустым.
- Захват без `FOR UPDATE SKIP LOCKED` — критично: две реплики возьмут одну единицу.
- Обработчик без проверки состояния до действия — критично для денег.
- Бесконечные повторы без предела и очереди разбора.
- Захваты без возврата зависших: единица блокируется навсегда.
- `LocalDateTime.now()`, расписание константой, отсутствие метрик очереди.
