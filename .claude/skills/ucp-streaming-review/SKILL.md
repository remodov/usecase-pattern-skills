# Потоковые соединения — ревью (Java / Spring Boot)

## Инструкции

1. **Прочитай** `.claude/docs/backend/streaming/spec.md`; идиома — `references/java/implementation.md`.
2. **Определи объект ревью:** названные файлы либо `git diff` — контроллеры с `SseEmitter` и `StreamingResponseBody`, обработчики WebSocket, перехватчики установления соединения, реестры подписок.
3. **Прогон по требованиям** `streaming/*`; формат находки — `shared/review-format/spec.md`.

## На что смотреть в первую очередь

- Аутентификация после принятия соединения — критично.
- Права проверены только на входе, а не на подписку, — критично: доступ к соединению не равен доступу к данным.
- Очередь на получателя без предела — падает сервис, а не медленный клиент.
- Транзакция или соединение с базой на всё время потока — критично под нагрузкой.
- Разрыв клиента не отменяет серверную работу.
- Рассылка через локальный реестр при нескольких экземплярах: часть клиентов не получит событий.
- Содержимое сообщений в журнале; отсутствие метрик числа соединений.
